# Kamal Express Travel PWA

Responsive, installable travel inquiry prototype for flights, visas, Umrah and hotels.

## GitHub Pages review
This repository deploys automatically with GitHub Actions to:
https://amrshah.github.io/kamal-express-travel-pwa/

The current review build is a standalone frontend demo. Inquiry submissions are simulated locally; it is not connected to a live CRM, Copilot/AG-UI runtime, or flight inventory API. Do not enter real customer or payment data.

## Deployment
Push to `main`; the workflow builds and deploys the static app to GitHub Pages. In repository Settings → Pages, choose **GitHub Actions** as the build and deployment source if it is not already selected.
